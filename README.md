# 🛍️ Yuvaa Ecommerce

## 📌 About the Project

Yuvaa Ecommerce is an online shopping web application developed using **Python and Django**. It allows users to browse products, add items to their shopping cart, manage orders, and enjoy a simple shopping experience.

## ✨ Features

- User Registration and Login
- Browse and View Products
- Product Categories
- Search Products
- Add Products to Shopping Cart
- Wishlist Management
- Product Reviews and Ratings
- Order Placement and Tracking
- Payment Integration
- Admin Panel for Managing Products and Orders

## 🛠️ Technologies Used

- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** SQLite
- **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.8 or higher
- pip
- Git

### 1. Clone the Repository

    git clone <repository-url>

### 2. Navigate to the Project Directory

    cd Yuvaa-Ecommerce

### 3. Create a Virtual Environment

    python -m venv venv

### 4. Activate the Virtual Environment

**Windows:**

    venv\Scripts\activate

**Mac/Linux:**

    source venv/bin/activate

### 5. Install Dependencies

    pip install -r requirements.txt

### 6. Apply Database Migrations

    python manage.py migrate

### 7. Run the Development Server

    python manage.py runserver

### 8. Access the Application

Open your browser and visit:

[http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## 🎯 Project Objective

To develop a user-friendly e-commerce web application using Django and gain practical experience in Python, database management, user authentication, and web development.
